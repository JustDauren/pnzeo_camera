3. Add these new methods:

   a) `async def get_ftp_params(self) -> dict[str, Any]`:
      - Sends `build_cgi_url(CGI_GET_FTP, ...)`
      - Response contains: ftp_svr (server), ftp_port, ftp_user, ftp_dir (upload path), ftp_mode (0=PORT, 1=PASV), ftp_upload_interval
      - Stores in `self._camera_params` under "ftp" namespace
      - Returns the FTP config dict

   b) `async def set_ftp(self, server: str, port: int = 21, user: str = "", password: str = "", directory: str = "/", mode: int = 1, upload_interval: int = 0) -> bool`:
      - Sends `build_cgi_url(CGI_SET_FTP, ..., ftp_svr=server, ftp_port=port, ftp_user=user, ftp_pwd=password, ftp_dir=directory, ftp_mode=mode, ftp_upload_interval=upload_interval)`
      - mode: 0=PORT, 1=PASV (passive mode, usually needed)
      - upload_interval: 0=every alarm, N=every N seconds
      - Returns success boolean

   c) `async def get_mail_params(self) -> dict[str, Any]`:
      - Sends `build_cgi_url(CGI_GET_MAIL, ...)`
      - Response contains: mail_svr (SMTP server), mail_port, mail_user, mail_sender, mail_receiver1..4, mail_ssl (0/1)
      - Stores in `self._camera_params` under "mail" namespace
      - Returns the mail config dict

   d) `async def set_mail(self, smtp_server: str, smtp_port: int = 587, user: str = "", password: str = "", sender: str = "", receiver: str = "", ssl: int = 1) -> bool`:
      - Sends `build_cgi_url(CGI_SET_MAIL, ..., mail_svr=smtp_server, mail_port=smtp_port, mail_user=user, mail_pwd=password, mail_sender=sender, mail_receiver1=receiver, mail_ssl=ssl)`
      - ssl: 0=off, 1=TLS/STARTTLS
      - Returns success boolean

   e) `async def set_push_token(self, token: str) -> bool`:
      - Sends `build_cgi_url(CGI_SET_FCM, ..., token=token)`
      - This registers an FCM push notification token so camera can send push alerts
      - If CGI endpoint does not work (MSG_SET_FCM_PUSH=97 may use binary protocol instead), log a warning and return False
      - Returns success boolean
