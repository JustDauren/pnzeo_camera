3. Add these new methods (following existing CGI patterns exactly):

   a) `async def wifi_scan(self) -> list[dict]`:
      - Sends `build_cgi_url(CGI_WIFI_SCAN, ...)` via `_send_cgi()`
      - Parses response for list of WiFi networks (each with SSID, signal strength, security)
      - Response format: key=value pairs like `ap_ssid[0]=NetworkName&ap_signal[0]=80&ap_security[0]=3`
      - Returns list of dicts: `[{"ssid": "...", "signal": 80, "security": "WPA2"}, ...]`
      - If response is empty or fails, returns empty list

   b) `async def set_wifi(self, ssid: str, password: str, security: int = 3) -> bool`:
      - Sends `build_cgi_url(CGI_SET_WIFI, ..., ssid=ssid, pwd=password, mode=security, enable=1)`
      - security: 0=none, 1=WEP, 2=WPA, 3=WPA2
      - Returns success boolean

   c) `async def get_wifi_params(self) -> dict[str, Any]`:
      - Sends `build_cgi_url(CGI_GET_WIFI, ...)`
      - Stores WiFi params (current SSID, signal, mode) in `self._camera_params` under "wifi" namespace
      - Returns the wifi dict

   d) `async def get_network_params(self) -> dict[str, Any]`:
      - Sends `build_cgi_url(CGI_GET_NETWORK, ...)`
      - Stores network params (ip, mask, gateway, dns) in `self._camera_params` under "network" namespace
      - Returns the network dict

   e) `async def get_ddns_params(self) -> dict[str, Any]`:
      - Sends `build_cgi_url(CGI_GET_DDNS, ...)`
      - Returns DDNS settings dict

   f) `async def set_ddns(self, service: str, hostname: str, user: str, password: str, port: int = 80) -> bool`:
      - Sends `build_cgi_url(CGI_SET_DDNS, ..., ddns_service=service, ddns_host=hostname, ddns_user=user, ddns_pwd=password, ddns_port=port)`
      - Returns success boolean

   g) `async def get_users(self) -> list[dict]`:
      - Sends `build_cgi_url(CGI_GET_USER, ...)`
      - Parses response for user slots (up to 3 users)
      - Response format: `user1=admin&pwd1=8888&user2=&pwd2=&user3=&pwd3=`
      - Returns list of dicts: `[{"slot": 1, "username": "admin"}, ...]` (passwords NOT returned for security)

   h) `async def set_users(self, user1: str = "", pwd1: str = "", user2: str = "", pwd2: str = "", user3: str = "", pwd3: str = "") -> bool`:
      - Sends `build_cgi_url(CGI_SET_USER, ..., user1=user1, pwd1=pwd1, user2=user2, pwd2=pwd2, user3=user3, pwd3=pwd3)`
      - WARNING: This overwrites ALL 3 user slots. Always GET first.
      - Returns success boolean
      - If the primary user (slot 1) password is changed, update `self.password`
