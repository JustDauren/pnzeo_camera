**binary_sensor.py** (CONN-04, ALRM-05):
- Import: `BinarySensorEntity, BinarySensorDeviceClass` from `homeassistant.components.binary_sensor`
- Import: `EntityCategory` from `homeassistant.helpers.entity`
- Standard `async_setup_entry(hass, entry, async_add_entities)` function
- Two entity classes:

1. `PNZEOConnectionBinarySensor(PNZEOEntity, BinarySensorEntity)` (CONN-04):
   - `_attr_device_class = BinarySensorDeviceClass.CONNECTIVITY`
   - `_attr_entity_category = EntityCategory.DIAGNOSTIC`
   - `__init__`: call `super().__init__(coordinator, "connection_status", "Connection")`
   - `is_on` property: `return self.coordinator.data.get("connection_state") == "CONNECTED"`
   - Override `available` to always return `True` (sensor must be visible even when disconnected)
   - `extra_state_attributes` property: return `{"connection_method": self.coordinator.data.get("connection_method", "unknown")}`

2. `PNZEOMotionBinarySensor(PNZEOEntity, BinarySensorEntity)` (ALRM-05):
   - `_attr_device_class = BinarySensorDeviceClass.MOTION`
   - `__init__`: call `super().__init__(coordinator, "motion_detected", "Motion Detected")`
   - `is_on` property: `return self.coordinator.data.get("motion_armed", "0") == "1"`
   - Note: This reflects the motion_armed state from alarm params polling. True real-time detection would need DRW alarm packets, but polling-based state satisfies ALRM-05.

**sensor.py** (SDCD-01, SYST-02):
- Import: `SensorEntity, SensorDeviceClass, SensorStateClass` from `homeassistant.components.sensor`
- Import: `EntityCategory` from `homeassistant.helpers.entity`
- Import: `UnitOfInformation` from `homeassistant.const`
- Standard `async_setup_entry` function
- Entity classes:

1. `PNZEOSDTotalSensor(PNZEOEntity, SensorEntity)` (SDCD-01):
   - `_attr_device_class = SensorDeviceClass.DATA_SIZE`
   - `_attr_native_unit_of_measurement = UnitOfInformation.MEGABYTES`
   - `_attr_state_class = SensorStateClass.MEASUREMENT`
   - `_attr_entity_category = EntityCategory.DIAGNOSTIC`
   - `_attr_icon = "mdi:sd"`
   - `__init__`: `super().__init__(coordinator, "sd_total", "SD Card Total")`
   - `native_value` property: parse `coordinator.data.get("sdtotal")`, return `int` value or `None`

2. `PNZEOSDFreeSensor(PNZEOEntity, SensorEntity)` (SDCD-01):
   - Same pattern as above but key=`"sd_free"`, name=`"SD Card Free"`
   - `native_value`: parse `coordinator.data.get("sdfree")`, return `int` value or `None`

3. `PNZEOSDUsedSensor(PNZEOEntity, SensorEntity)` (SDCD-01):
   - Same pattern but key=`"sd_used"`, name=`"SD Card Used"`
   - `native_value`: compute `sdtotal - sdfree` if both present, else `None`

4. `PNZEOFirmwareSensor(PNZEOEntity, SensorEntity)` (SYST-02):
   - `_attr_entity_category = EntityCategory.DIAGNOSTIC`
   - `_attr_icon = "mdi:chip"`
   - `__init__`: `super().__init__(coordinator, "firmware_version", "Firmware Version")`
   - `native_value` property: return `coordinator.data.get("sysver", coordinator.device.client.state.get("firmware", "unknown"))`

5. `PNZEODeviceNameSensor(PNZEOEntity, SensorEntity)` (SYST-02):
   - `_attr_entity_category = EntityCategory.DIAGNOSTIC`
   - `_attr_icon = "mdi:tag"`
   - `__init__`: `super().__init__(coordinator, "device_name_info", "Device Name Info")`
   - `native_value` property: return `coordinator.data.get("devname", coordinator.device.name)`

`async_setup_entry` creates all 5 sensors: `[PNZEOSDTotalSensor(c), PNZEOSDFreeSensor(c), PNZEOSDUsedSensor(c), PNZEOFirmwareSensor(c), PNZEODeviceNameSensor(c)]`

**event.py** (ALRM-06):
- Import: `EventEntity, EventDeviceClass` from `homeassistant.components.event`
- Standard `async_setup_entry` function
- `PNZEOAlarmEvent(PNZEOEntity, EventEntity)`:
   - `_attr_device_class = EventDeviceClass.MOTION`
   - `_attr_event_types = ["motion", "gpio", "sound"]`
   - `__init__`: `super().__init__(coordinator, "alarm_event", "Alarm Event")`
   - Track previous `motion_armed` state in `self._prev_motion_armed: str | None = None`
   - Override `_handle_coordinator_update(self)`:
     - Get current `motion_armed = self.coordinator.data.get("motion_armed", "0")`
     - If `self._prev_motion_armed is not None` and previous was `"0"` and current is `"1"`:
       - Call `self._trigger_event("motion", {"source": "polling"})`
     - Update `self._prev_motion_armed = motion_armed`
     - Call `super()._handle_coordinator_update()`
   - This fires HA events when motion_armed transitions 0->1 between polling cycles

Note: Do NOT use `_attr_should_poll = True` -- the coordinator handles all polling. Use `_handle_coordinator_update` to detect state transitions.
