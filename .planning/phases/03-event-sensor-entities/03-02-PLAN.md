Implement `async_get_config_entry_diagnostics(hass: HomeAssistant, entry: ConfigEntry) -> dict[str, Any]`:

1. Get coordinator: `coordinator: PNZEOCoordinator = hass.data[DOMAIN][entry.entry_id]`
2. Get client: `client = coordinator.device.client`
3. Build and return dict with these sections:

```python
{
    "config_entry": async_redact_data(entry.as_dict(), TO_REDACT),
    "connection": {
        "state": client.connection_state.name,
        "method": client.connection_method,
        "pppp_available": coordinator.pppp_available,
        "host": coordinator.device.host,
        "device_id": coordinator.device.device_id,
    },
    "capabilities": client.capabilities,
    "camera_state": async_redact_data(
        dict(coordinator.data) if coordinator.data else {},
        TO_REDACT,
    ),
}
```

Key implementation details:
- Use `async_redact_data` from HA to mask passwords/usernames in both config_entry and camera_state
- `client.capabilities` is the raw dict from check_user.cgi RTGetCapability -- dump it as-is (DIAG-02)
- `coordinator.data` contains ALL polled camera state (alarm params, camera params, status) -- dump it for debugging (DIAG-01)
- `connection` section shows protocol state for troubleshooting connection issues (DIAG-01)
- No need to add Platform entry -- HA auto-discovers diagnostics.py in the integration folder
